# Development Discussion Records

Use this folder to track development discussions as markdown records.

## Filename format

`<status>_<topic>.md`

- `<status>`: `todo`, `planning`, `developing`, `finished`, `pending`
- `<topic>`: lowercase hyphenated slug (example: `preserve-target-dev-branches`)

## Status lifecycle

Common flow:

`todo` -> `planning` -> `developing` -> `finished`

Use `pending` when the item is intentionally paused or waiting on external input.

When status changes, rename the file to the new status prefix.

## Record template

```md
# <Human-readable title>

## Question
...

## Summary
...

## Decisions
...

## Pros and cons
...

## Next steps
...
```
